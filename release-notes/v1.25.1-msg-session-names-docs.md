# v1.25.1 — reliable agent messages and named `aichat` sessions

v1.25.1 makes day-to-day agent coordination and session management more
reliable, with a polished docs landing page to match.

## New: reliable `msg` delivery and notifications (PR #167)

`msg` now handles real interactive Claude Code and Codex sessions more safely.
Delivery, inbox reads, retargeting, unregistering, and watcher cleanup are
race-safe; migrations repair older registrations and malformed leases.

Notifications respect an in-progress prompt: the watcher distinguishes dim
placeholder text from text that you have actually typed, so an incoming message
does not overwrite your work. It also uses hook responses and inbox prompts
accepted by current Claude Code and Codex.

The release includes a complete `msg` guide covering setup, routing,
notifications, and lifecycle behavior.

Docs: [msg](https://pchalasani.github.io/claude-code-tools/tools/msg/)

## New: use session names with every `aichat` action (PR #172)

Every session-taking `aichat` command now accepts a session name, ID,
filename fragment, or path. That includes `delete`, `menu`, the bare
`aichat <session>` shortcut, lineage commands, exporters, `port`, and
`move-account`.

When a name matches multiple sessions, interactive commands show a
newest-first picker before acting. JSON and piped modes stay deterministic and
never prompt; cancelling a picker makes no change.

Docs:
[aichat actions](https://pchalasani.github.io/claude-code-tools/tools/aichat/actions/)

## Improved: documentation landing page and Codex workflows guide (PRs #170, #171)

The README and documentation landing page now use a balanced feature-card grid,
including a restored amux card and refreshed artwork for session porting,
GitHub wakeups, and Codex Dynamic Workflows.

The former Claude-to-Codex guide is now titled **Codex Dynamic Workflows**. It
opens by explaining that the plugin is the Codex counterpart to Claude Code's
dynamic workflows, while making its remaining limitations clear.

Docs:
[Codex Dynamic Workflows][workflows]

## Maintenance: tmux controller tests (PR #173)

The tmux pane-creation fixtures now match the current controller command
sequence, keeping coverage aligned with the production behavior.

[workflows]: https://pchalasani.github.io/claude-code-tools/guides/claude-to-codex/
