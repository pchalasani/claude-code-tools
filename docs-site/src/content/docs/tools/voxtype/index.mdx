`voxtype` turns speech into text in whatever app
has focus -- your editor, browser, terminal, or a
coding agent's prompt box. Everything runs on your
machine: no cloud, no accounts, no audio leaving
your Mac.

:::caution[macOS only — Intel and Apple Silicon]
voxtype relies on macOS APIs for typing (accessibility),
hotkey suppression (the CGEvent tap), and its overlay
(AppKit). **It is not supported on Linux or Windows** —
there the toggle hotkey can't be suppressed (it leaks
into your text), there is no overlay, and it is
untested. On Macs it works on both **Intel** and
**Apple Silicon**: Apple Silicon (M1 or later) defaults
to the `parakeet-mlx` Apple-GPU engine; Intel Macs use
the `parakeet` CPU engine (`moonshine` ships no
Intel-macOS build).
:::

## Let your agent set it up

Install the `voxtype-install` skill into your coding agent, then ask it
to do the rest:

```bash
npx skills add pchalasani/claude-code-tools -s voxtype-install
```

That one command (it needs Node.js 22.20 or newer for `npx`) installs only this skill (not the rest of this repo)
into Claude Code, Codex, Cursor, Gemini CLI, and most other agents, for
the current project; add `-g` for every project. Then say "install
voxtype and set it up" — the agent installs the CLI, explains the config
options, and walks you through the macOS permission prompts. Prefer to do
it by hand? Read on.

Already have voxtype installed? `voxtype skill` sets up the same skill for
Claude Code and Codex through their plugin marketplaces.

## Quick start

<Steps>

1. Install — the best engine for your machine comes
   bundled automatically (Apple-GPU `parakeet-mlx` on
   Apple Silicon, CPU `parakeet` on Intel):

   ```bash
   uv tool install voxtype
   ```

   Upgrade later with `uv tool upgrade voxtype` (it
   keeps any extras).

2. Grant your terminal **Microphone**,
   **Accessibility**, and **Input Monitoring**
   permissions (System Settings → Privacy &
   Security) when prompted.

3. Start dictating:

   ```bash
   voxtype
   ```

   Press `Ctrl+;` to start, speak (watch the ghost),
   press `Ctrl+;` again to stop -- your speech is typed
   at the cursor. `Esc` cancels a take.

4. Configure it: run `voxtype setup` for an
   interactive walkthrough — it asks a handful of
   explained questions (engine, mode, hotkey, ...) and
   writes your `~/.config/voxtype/config.toml`. (Prefer
   editing by hand? `voxtype init` drops a fully
   commented sample instead.)

</Steps>

## Make it yours

Almost everything is a choice: how dictation activates
(hotkey, wake word, or always-on), how speech becomes
text (whole-take vs. per-pause), which local engine
runs it (Apple-GPU Parakeet, CPU Parakeet, or
Moonshine), plus hotkeys, sounds, optional clipboard
mirroring, and more. The complete reference -- every
config key with its default, the engine comparison, and
all CLI flags -- lives in
**[Configuration & CLI](./configuration/)**.
To try any setting for one run without editing the
file, use `--set`, e.g.
`voxtype --set post-process=true --set post-process-provider=s1-mini`
turns on local cleanup for that run.

## Hotkey & voice vocabulary

| Action | Default | Configurable as |
|--------|---------|-----------------|
| Toggle recording | `Ctrl+;` | `hotkey` |
| Cancel recording (discard) | `Esc` (only while recording; not hands-free) | `cancel_hotkey` |
| Discard held text (hands-free) | `Shift+Esc` (keeps listening) | `discard_hotkey` |
| Re-type last transcript | off | `paste_hotkey` |
| Submit (press Enter) | say "go" / "over" / "submit" | `submit_phrases` |
| Type, then submit | end with "…, send it", "…, go do it", "…, ok go" or "…, over and out" | `submit_suffixes` |
| Type for review (hands-free) | end with "…, ok show" or "…, type it" | `show_suffixes` |
| Stop dictating (vad segmentation) | say "stop listening" | `stop_phrase` |

In the default toggle + `hold` setup you stop by pressing the toggle
hotkey again; the spoken `stop_phrase` only applies to per-utterance
(vad) transcription — i.e. wake mode or `segmentation = "vad"`.

### Talk, then submit in one breath

End what you say with a submit phrase ("send it", "go do it", "go to
it", "ok go", "now go" or "over and out") and voxtype types everything
before the phrase, then presses Enter. No pause is needed: "fix the
build before the demo, send it" types "fix the build
before the demo" and submits it. The phrase only counts at the very
end, so "we ran over and out of time" is typed as said. Said on its
own, the phrase just presses Enter, like "go".

This pairs well with hands-free dictation, where nothing needs a
hotkey: set `mode = "vad"`, talk, and say "send it" to send. In this mode
voxtype holds your words back until the submit phrase, so you can pause
to think as often as you like: everything since the last submit is
typed as one piece and sent. With LLM cleanup on, that piece is cleaned
as a whole, so a list spread over several pauses still comes out as one
list. `Ctrl+;` pauses listening (say, while
you talk to someone) and types anything held, without Enter. `Esc` is
left alone in this mode, so it keeps working in your apps; to throw away
what you've said since the last submit, press `Shift+Esc` instead.
Nothing is typed and voxtype keeps listening (`discard_hotkey`). Set
`wait_for_submit = false` to have each piece typed as soon as you pause
instead.

To look before you send, end with "ok show" (or "ok show me", "now
show me", "type it", "tap it") instead: the held text is typed without
Enter and voxtype keeps listening. Read it, fix it by hand if needed,
then say "go" (or "send it") to press Enter. The transcriber often hears
"ok show" as "ok sure", and "ok show me" as "ok shall we" or "ok so me",
so those count too. It also hears "send it" as "senate", which submits
like "send it". Change these phrases with `show_suffixes` and
`submit_suffixes`.

The phrases are matched on the raw transcript, before filler removal
and LLM cleanup, so cleanup cannot remove them. Change the list with
`submit_suffixes`; `[]` turns the feature off. A phrase that ends an
ordinary sentence ("…and then we send it") also submits, so drop any
that trip you up.

Not sure how to spell a chord for the hotkey settings
above? Run `voxtype hotkey`, press the combo you want,
and it prints a ready-to-paste `hotkey = "..."` line
(use the same chord string for `cancel_hotkey` / `discard_hotkey` /
`paste_hotkey`).
